# 合约全市场多周期预测与计划生成设计（研究版 v32）

> 2026-09 更新：v32 不删除此前能生成计划的直接模型，而是在同一四尺度输入和订单语义上增加概率预测、训练集相似状态检索与组内计划排序。检索结果只是候选，仍由当前状态的 critic/质量头复评分。

## 研究依据

本设计把“预测未来”与“选择可执行计划”拆成两个相互约束的层，而不是让一个分类器直接猜买卖信号：

- [TimesFM](https://arxiv.org/abs/2310.10688) 与 [Chronos](https://arxiv.org/abs/2403.07815)：用大规模预训练/概率输出学习跨序列的未来分布，适合把 q10/q50/q90 和方向概率作为计划生成的上游信息。
- [Moirai](https://arxiv.org/abs/2402.02592) 与 [MOMENT](https://arxiv.org/abs/2402.03885)：统一多数据集、多变量时间序列的表示，支持不同合约和不同波动状态共享编码器。
- [PatchTST](https://arxiv.org/abs/2211.14730)、[iTransformer](https://arxiv.org/abs/2310.06625) 与 [TimeMixer](https://arxiv.org/abs/2405.14616)：分别提供 patch 化长上下文、变量/时间维度重排和多尺度分解混合的结构依据。
- [Timer-XL](https://arxiv.org/abs/2410.04803) 与 [Time-MoE](https://arxiv.org/abs/2409.16040)：说明因果长上下文和容量可扩展的专家/分支结构对跨周期预测有价值；当前先采用轻量尺度分支，避免在本地数据规模下盲目增大参数。
- [RAFT](https://arxiv.org/abs/2505.04163)：检索相似历史片段的未来轨迹可补足单一神经预测器；本地回放语料可作为后续检索增强层。
- [Decision-Focused Forecasting](https://arxiv.org/abs/2405.14719)：预测应直接服务多阶段决策。因此计划质量头监督同一动作的回放结果，而不是模仿经典策略教师。
- [Decision Transformer](https://arxiv.org/abs/2106.01345) 与 [Trajectory Transformer](https://arxiv.org/abs/2106.02011)：离线决策应把状态、动作和回报/轨迹放在同一序列条件中；本项目采用轻量动作条件化 critic，而不是把经典策略输出当标签。
- [RankNet](https://doi.org/10.1145/775047.775067) 与 [LambdaRank](https://doi.org/10.1145/1102351.1102423)：全市场扫描是排序问题。组内 pairwise ranking loss 直接约束同一状态下高效计划高于低效计划，减少绝对回报回归造成的排序漂移。
- [Conformal Risk Control](https://arxiv.org/abs/2202.05886)：预测区间与选择风险应一起校准；v32 将未来分位数宽度送入计划候选尺度与排序惩罚，并保留验证集风险—覆盖率校准。
- CQL/IQL（[CQL](https://arxiv.org/abs/2006.04779)、[IQL](https://arxiv.org/abs/2110.06169)）：离线 critic 对分布外动作可能过度保守；WAIT 只能作为基线，不能成为第二个严格分类器。
- Conformal Prediction（[综述](https://arxiv.org/abs/2107.07511)）：未来可用滚动校准把预测区间宽度转换为风险预算和置信度。

## 模型模块

1. **因果多尺度状态编码器**：4h/1h/15m/5m 各自保留完整已收盘窗口，patch 分支捕获局部结构，共享 Transformer 融合跨尺度关系；5m 是时间锚点和执行粒度。
2. **未来分布预测器**：输出未来 4/12/24 根 5m 的 q10/q50/q90 对数收益和方向概率。分位数单调参数化，避免区间交叉。
3. **预测条件化计划生成器**：计划头读取状态表示与未来分布，输出方向、触发区、止损、双目标、两档比例、四阶段移动止损和时间成本。
4. **预测引导候选格**：actor 的中心计划周围同时搜索 STOP 与 LIMIT 两侧几何；触发符号不与 LONG/SHORT 硬绑定。未来分布的短/中/长 horizon 方向、空间和不确定性只用于生成候选邻域，最终由 critic 评分。
5. **相似历史状态检索**：训练集每个因果状态保留其已回放的高效非 WAIT 动作，形成小型 bank。线上按归一化四尺度状态检索邻近状态，把其动作加入候选格；检索动作仍经过当前状态 critic、成交概率、达标概率和风险尾部评估，避免行为复制和未来泄漏。
6. **动作条件化分布 critic**：对每个具体候选输出收益分位数、回撤分位数、成交概率、达标概率、结果和持仓时长，并额外输出 `expectedR / winProbability / drawdownRisk / timeEfficiency / confidence`。
7. **组内排序损失**：同一状态下对不同动作使用加权 pairwise logistic loss，训练目标是把高 realized utility 的候选排在低 utility 候选之前；WAIT 保持基线，不被当作唯一分类门槛。
8. **风险—覆盖率选择器**：按 WAIT 基线、保守收益、回撤、时间成本和质量头排序；校准时搜索完整的正负 margin 曲线。校准不到安全工作点时，WAIT 只作为参考动作，改用显式分数下限、成交/达标支持、下尾收益、回撤和不确定性组成有界回退，不能把所有候选强制变为 WAIT。
9. **全市场前沿**：每个 USDT 永续合约独立进行因果推理，服务端按模型选择分数、质量、时间效率和风险回报比排序，只展示少量最高质量计划。

## 当前实现映射

- `backend/services/binance_ml.py` 已保留四尺度输入、未来分布头、质量头和动作 critic。
- `forecast_guided_actions()` 将未来分布转为候选计划格，并与 actor 邻域合并后统一由 critic 选择。
- `_build_retrieval_bank()` 仅从训练分区构建 RAFT 风格相似状态动作库；`_retrieval_guided_actions()` 只增加候选，不绕过当前状态评分。
- `_groupwise_action_ranking_loss()` 让训练直接优化同一行情状态下的计划排序。
- `decode_direct_plan_prediction()` 显式区分 STOP/LIMIT；两侧触发几何都可进入回放和实时计划。
- `backend/services/binance_futures_strategy.py` 与 `backend/services/binance_strategy_backtest.py` 共享同一订单语义和计划排序。
- 回测只使用 5m 最小执行 K 线；同根 K 线无法确定先后时采用方向不利路径，不读取 1m。

## 训练与评估

训练样本仍是同一因果状态下的 WAIT/LONG/SHORT 多动作回放结果，不保存经典策略教师计划。除覆盖率外，必须同时观察：

- 方向/分位数预测误差与方向准确率；
- 质量头的 expected-R、胜率、回撤和时间效率误差；
- 风险—覆盖率曲线，而不是单一准确率；
- 全市场扫描返回数量、计划成交率、胜率、实现 R、持仓时间和最大回撤。

任何新检查点都必须记录模型版本、输入周期、窗口、输出结构、订单语义和语料指纹；结构或语义不兼容时不可加载，也不回退经典策略。

## 本轮实证修正

- 训练、校准和在线选择共用同一套风险—覆盖率规则；当验证集找不到
  Wilson 安全点时，WAIT 不再作为硬分类器，而是退回到显式分数下限与
  回撤/不确定性约束。
- `STABLE` 只能从自身具有有效校准评分的后期 epoch 中选择，不能因为邻近
  epoch 的平滑分数而选中无效末轮。
- 2026-09-15 的 GPU 重训在验证集得到约 8.5% 覆盖率、56.3% 选择胜率；
  时间外测试约 3.5% 覆盖率、38.8% 胜率，说明当前编码器仍存在跨阶段泛化
  不足。该结果会保留在研究列表中，不能仅凭验证集指标宣称模型已稳定。
