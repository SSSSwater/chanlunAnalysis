# 合约多周期预测—计划质量模型设计（v31）

## 资料依据（2024—2026）

- **TimeMixer**（arXiv:2405.14616）将趋势与短期变化分解后做多尺度混合；用于 4h/1h/15m/5m 的共享状态与局部 patch 分支。
- **Timer-XL**（arXiv:2410.04803）、**Time-MoE**（arXiv:2409.16040）表明长上下文、因果建模和稀疏专家有助于跨时间尺度迁移；本实现保留轻量 Transformer，在数据量有限时先用尺度分支而非盲目扩大参数。
- **RAFT**（arXiv:2505.04163）用相似历史片段的未来轨迹补充预测器，说明计划质量不能只依赖单点回归；后续可将本地回放语料作为检索增强层。
- **ProbFM**（arXiv:2601.10591）强调把偶然不确定性与模型不确定性分开；本实现使用预测区间、critic 分位数和显式质量向量共同表达不确定性。
- **Decision-Focused Forecasting**（arXiv:2405.14719）指出预测应对下游多阶段决策负责；本实现的计划质量头直接由同一动作回放结果监督，而不是模仿人工教师计划。
- **TSBench 超参数研究**（arXiv:2403.04477）显示 context length、验证方式和粒度会显著影响效果；窗口、horizon、回放次数和选择门槛均作为训练记录的一部分保存。
- **CQL/IQL**（arXiv:2006.04779、2110.06169）提醒离线 critic 对分布外动作可能过度保守或虚高；动作空间保留正负两侧几何，WAIT 只作基线，不能用方向符号硬删除样本。
- **Conformal Prediction**（arXiv:2107.07511）提供模型无关的区间校准方法；当前版本用分位数宽度和风险覆盖校准约束计划准入，后续可接入滚动 conformal scale。

## v31 模块

1. **多尺度因果编码器**：4h/1h/15m/5m 各自使用 patch/Conv 分支，按时间尺度 embedding 后进入共享 Transformer，并融合每个尺度的最新状态。
2. **未来分布预测器**：预测未来 4/12/24 根 5m 的 q10/q50/q90 对数收益和方向概率；分位数单调参数化，避免区间交叉。
3. **预测条件化计划生成器**：计划头读取市场状态和未来分布，不读取经典策略候选，输出触发区、止损、双目标、目标分配、四阶段移动止损和时间成本。
4. **动作条件化回放 critic**：对每个具体几何预测收益分位数、回撤、成交、达标、结果和持仓时长。回放保留 LONG/SHORT 的正负触发几何，不在预处理阶段加安全侧硬过滤；顺势侧按 STOP、回撤侧按 LIMIT 的订单语义分别回放。
5. **显式计划质量头**：输出 `expectedR / winProbability / drawdownRisk / timeEfficiency / confidence`。五项由同一因果回放结果监督，并作为有界排序项加入收益—回撤分数。
6. **风险—覆盖率选择器**：WAIT 是零仓位基线；先比较保守收益和 WAIT，再用经验胜率、Wilson 下限、预测区间宽度和质量头排序。全市场只返回少量最高分可执行计划，WAIT 不占名额。

## 与旧逻辑的关键区别

- 不把 LONG 触发价强制限定在参考价上方，也不把 SHORT 强制限定在下方；这会丢掉半数动作空间并恶化覆盖率。
- 不用经典策略给模型生成“教师计划”。模型学习的是历史状态、具体动作与未来回放结果之间的关系。
- 预测质量和计划质量分开记录：前者描述未来走势分布，后者描述某个具体点位组合是否值得执行。
- 模型文件带有 v30、任务类型、输入周期、输出质量头指纹；v29 及更早检查点不自动加载。

## 运行输出

`modelPrediction` 和 `modelStrategy` 同时提供：未来各 horizon 的区间、方向概率、保守收益、回撤、时间效率、质量五元组、WAIT 分数、选择原因和最终计划。扫描器在这些字段上排序，仅展示少数最佳计划。
